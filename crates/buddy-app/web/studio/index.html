Clips

The art. Each row is one group of clips (a folder under art/). Draw in Aseprite, then add the file here; tags become clips, a trailing _S, _SE… is the direction.

Drop an .aseprite file here or
Pixels are copied unchanged. Nothing is written unless the whole file checks out.

To retouch frames, open the folder and edit the PNG strips in your pixel editor: the studio reloads as you save.

Behaviors

A behavior is a short sequence of clips. Reactions and idle life pick behaviors by name.

Reactions to events

What the mascot does when something happens. Each row is tried left to right; the first behavior whose clips exist plays.

Idle life

What it does on its own. A higher weight plays more often; the cooldown keeps one from repeating. Run Review › Audit to see a simulated half hour.

Timing rules, time-of-day and seasonal entries: Advanced.
